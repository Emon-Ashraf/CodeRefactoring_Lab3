# Personal Finance Management · Refactoring Lab 3

A C# console application for tracking income and expenses across wallets. This lab focuses on refactoring the login flow, transaction handling, password handling, and wallet methods.

## Features

- Create wallets and record income and expenses.
- Review wallet details and transaction statistics.
- Store user and wallet data locally as JSON.

## Getting Started

Install the .NET 8 SDK and run from the repository root:

```sh
dotnet run --project CodeRefactoring_Lab3
```

The [refactoring notes](Commit%20discriptions/) document the four issues addressed in the lab.
